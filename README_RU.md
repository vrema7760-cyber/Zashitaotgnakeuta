# TG Guard — бот, инлайн-кнопки и Web App

## Что внутри

- `src/index.js` — Telegram webhook, обработка каналов и групп, модерация и API Web App.
- `src/ui.js` — клавиатуры Telegram. Обычные кнопки «Чаты и каналы» и «База ботов» не зависят от настройки Web App.
- `webapp.html` — исходный HTML панели управления.
- `src/webapp.js` — HTML, встроенный в Worker без ошибок вложенных шаблонных строк.
- `scripts/build-webapp.mjs` — пересобирает `src/webapp.js` после изменения `webapp.html`.

## Развертывание через Wrangler

1. Установите Node.js и откройте терминал в этой папке.
2. Если TG Guard уже развёрнут, сохраните существующий KV binding `STATE` и его ID из `wrangler.toml` — новое хранилище создавать не нужно. Для совершенно новой установки создайте namespace командой `npx wrangler kv namespace create STATE` и укажите выданный ID в `wrangler.toml`.
3. Убедитесь, что секрет `BOT_TOKEN` настроен: `npx wrangler secret put BOT_TOKEN`. Вставьте токен в приглашение терминала; не записывайте его в исходный код.
4. Выполните `npm run build:webapp`, затем `npm run check`.
5. Опубликуйте Worker: `npx wrangler deploy`. Скопируйте HTTPS-адрес Worker из вывода команды.

В Cloudflare Worker должны быть доступны binding KV с именем `STATE` и secret `BOT_TOKEN`. Если вы используете другой способ публикации, убедитесь, что все три файла из `src/` опубликованы вместе.

## Обязательная настройка webhook Telegram

`allowed_updates` должен включать `callback_query`, иначе кнопки могут отображаться, но нажатия не будут доходить до Worker. После публикации выполните команду, заменив `BOT_TOKEN` и адрес Worker своими значениями:

```bash
curl -X POST "https://api.telegram.org/botBOT_TOKEN/setWebhook" \
  -H "Content-Type: application/json" \
  -d '{"url":"https://YOUR-WORKER.workers.dev/telegram/webhook","allowed_updates":["message","channel_post","callback_query","my_chat_member","chat_member","chat_join_request"]}'
```

Проверка состояния webhook:

```bash
curl "https://api.telegram.org/botBOT_TOKEN/getWebhookInfo"
```

После обновления кода отправьте боту `/start` заново. Кнопки показываются в новом сообщении; старые сообщения Telegram автоматически не обновляет.

## Web App

Путь панели: `https://YOUR-WORKER.workers.dev/app`. Кнопка Web App строится автоматически из HTTPS-домена Worker, если не задан `WEBAPP_URL`. При использовании отдельного домена задайте `WEBAPP_URL` как HTTPS URL панели. В BotFather привяжите домен бота через `/setdomain`, если Telegram требует такую привязку для вашего домена.

Web App использует подписанный `initData`, перепроверяет права текущего пользователя администратора на сервере и показывает только доступные ему чаты. Для изменения HTML отредактируйте `webapp.html`, выполните `npm run build:webapp` и повторно опубликуйте Worker.

## Модерация групп без капчи

1. Добавьте TG Guard в группу и назначьте его администратором. Для удаления сообщений выдайте право удалять сообщения, а для автоматического мута — право ограничивать участников. На практике муты поддерживаются в супергруппах; старую группу может потребоваться преобразовать в супергруппу.
2. Если бот уже был администратором до обновления и группа не появилась в панели, отправьте в группе команду `/setup` от имени администратора. Команда проверит права бота и зарегистрирует группу.
3. В личном чате с ботом откройте Web App, нажмите «Настроить» у нужной группы и включите нужные функции. Антиспам, антимат, ссылки и анти-рейд выключены по умолчанию. Капчи в проекте нет.
4. Для антимата задайте список слов и длительность мута. Сообщение с нарушением удаляется, пользователю выдаётся мут; при повторных нарушениях срок увеличивается до четырёх базовых интервалов. История действий и предупреждений доступна во вкладке «Модерация».
5. Анти-рейд отслеживает всплеск вступлений. При срабатывании на пять минут удаляются сообщения недавно вступивших участников; это не требует капчи. Ссылки и ненормативная лексика в публикациях канала могут удаляться, но мутить подписчиков канала Telegram не позволяет.

Бот должен получать обновления `message`, `chat_member` и `my_chat_member`. Администраторам лучше проверить webhook через `getWebhookInfo` после публикации. В группах TG Guard должен оставаться администратором для удаления сообщений и применения ограничений.

## Важные ограничения Telegram

Telegram Bot API не предоставляет дату создания аккаунта. Фото профиля и отдельные поля доступны не для всех пользователей/ботов. Фильтры могут ошибаться, поэтому проверяйте список запрещённых слов и настройки перед включением на большой группе.
